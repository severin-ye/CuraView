# Table guide · 逐表清单

Table numbers follow the 17 November manuscript returned on 18 November 2026. Each row identifies the analysis, input population and endpoint. The letters link each row to its implementation and prompt provenance below.

表号以 11 月 18 日收到的 11 月 17 日返稿为准。各行列出分析、数据范围与统计口径，字母对应下列模型、提示词与代码来源。

- **M · Main verification / 主实验** — [current detector](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/detection/doc/prompts/detection_prompt_paper_aligned.md) and [scoring](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/evaluation/formal_metrics.py). The paper identifies the models and endpoints. Exact historical prompt bytes, checkpoint identity and run commit for each main result are unverified. 以上链接为可查阅的现行实现，历史逐表提示词、检查点和运行提交未核实。
- **R · Recovered generation / 历史恢复** — The recovered study material documents the perturbation prompts. Its link to individual historical test results is unverified. 恢复材料列出历史提示词，缺少将其绑定到各张历史结果表的运行记录。
- **E · External evaluation / 外部评测** — [public input conversion](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/evaluation/official_baseline_inputs.py) and [metrics](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/evaluation/formal_metrics.py). Exact historical upstream executable revisions are unverified. 公开入口用于转换输入、计算指标；外部方法当次可执行版本未核实。
- **X · Single-case exploration / 单病例探索** — [public graph build](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/graph/README.md), [English Domain runtime prompt](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/graph/v33/prompts/domain.extract.txt), [detector](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/comparison/detection_prompt.md) and [strategy](https://github.com/severin-ye/CuraView/blob/9121b8cd786f172519e47618b44b31c3b90447c6/comparison/strategy.txt). Public runtime revision 9121b8c uses the English prompt. The archived study identifies a Chinese Domain input for the reported graphs. The public English run is a software verification with synthetic data; it did not produce the clinical table values. 公开版 9121b8c 运行英文构图提示词；留存实验资料记载本轮返稿所报告的图使用中文输入。英文版以合成输入验证，未据此重算论文临床数字。The revision supplement cites archived implementation snapshot 17e423bb; exact execution commit per table is unverified. 返稿附录引用的归档实现为 17e423bb，逐表实际运行提交未核实。
